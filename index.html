Things I've made

Small experiments that started from a real annoyance. They work, they're rough around the edges, and the code is public — feedback welcome.

AutoKI

01

Screenshot-driven Anki card maker for Windows and Linux. Press a hotkey, select the question, then the answer, and export a standard .apkg when you're done. Captures stay sharp, so equations and diagrams survive. Works offline, with an English and Arabic interface.

Touchy

02

An experiment in controlling the mouse with hand gestures through a webcam. Hand tracking picks the position, a pinch becomes a click. Fun to build, occasionally janky — as experiments should be.

PyFileExplorer

03

A keyboard-driven file explorer built while learning GUI programming. Navigate with WASD, jump to paths, search files. Mostly an excuse to understand how desktop apps are put together.
